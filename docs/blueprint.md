# **App Name**: SELISE-ITO Portal

## Core Features:

- Firebase User Authentication: Secure user login and registration with existing Firebase Project (ito-managment-portal) integration.
- Dashboard View: A central, personalized dashboard displaying an overview of key project metrics and issue statuses after login.
- GitHub Issues Integration: Connect with GitHub API to fetch and display project issues (tickets) from specified repositories.
- Dynamic Date Range Filtering: Provide a user interface tool for selecting a custom date range to filter and retrieve GitHub issues.
- Formatted Issue Data Display: Present the fetched GitHub issues in a clear, organized, and readable table or list format within the dashboard.
- AI Issue Summarization Tool: Offer an AI-powered tool to generate concise summaries for lengthy GitHub issue descriptions, enhancing quick understanding.

## Style Guidelines:

- Primary color: A sophisticated, professional blue (#2867BD) to evoke trust and efficiency in a corporate environment. This provides good contrast on a light background.
- Background color: A very light, desaturated blue (#EBF1F6) provides a clean and calm base for the portal content, improving readability.
- Accent color: A subtle, desaturated cyan (#A6E2E2) analogous to the primary, used for highlights and interactive elements without being overly vibrant.
- Headlines and Body text: 'Inter' (sans-serif) for its modern, clear, and highly readable design, ensuring optimal data consumption on the dashboard.
- Utilize a consistent set of minimal, outline-style icons to represent actions and data types clearly, maintaining a clean and professional aesthetic.
- Implement a clean, responsive dashboard layout with a clear navigation sidebar, main content area, and a modular system for displaying data widgets and issue lists.
- Incorporate subtle transitions and loading indicators for dashboard elements and data fetching processes to provide a smooth user experience.
